🔬 浮力实验演示

A、B用绳连接悬浮 → 剪断绳 → A漂浮 B沉底
状态1：A、B用绳连接，整体在液体中悬浮

📊 物理分析

🔵 A、B整体受力（状态1）

整体悬浮：浮力 = 重力

F浮总 = G_A + G_B

即：ρ液·g·(V_A+V_B) = ρ_A·g·V_A + ρ_B·g·V_B

📐 容器与桌面压强（状态1）

液体深度 h₁，容器底面积 S

P容器底 = ρ液·g·h₁
P桌面 = (G容+G液+G_A+G_B) / S

🟢 A漂浮的受力

A漂浮 → ρ_A < ρ液

F浮A = G_A（浮力=重力）

A部分露出液面，排开液体减少

🔴 B沉底的受力

B沉底 → ρ_B > ρ液

F浮B + N支 = G_B

容器底对B的支持力：

N支 = G_B - F浮B = (ρ_B - ρ液)·g·V_B

又因为整体浮力减少量等于A露出部分的浮力：

N支 = ρ液·g·V_A露出

N支 = (ρ_B - ρ液)·g·V_B = ρ液·g·V_A露出

📏 液面与容器底压强变化

V排₂ < V排₁（A不再完全浸没）→ 液面下降

h₂ < h₁

▼ 液体压强变小

P容器底₂ = ρ液·g·h₂ < ρ液·g·h₁

🖥️ 桌面压强变化

所有东西仍在容器中，总重不变

G总 = G容+G液+G_A+G_B（不变）

◆ 桌面压强不变

P桌面₂ = G总 / S = P桌面₁
